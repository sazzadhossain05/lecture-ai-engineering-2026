Based on Lecture 03, here is how compaction and memory differ, along with how daily notes are handled:

* **Compaction vs. Memory across sessions:** 
  * **Compaction** compresses history *within the loop* (inside the context of the same session) by replacing old history with a summary (Lecture 3, pp. 39, 65).
  * **Memory** operates *across sessions* using external storage (such as files or a memory tool), allowing the agent to carry information over to future sessions (Lecture 3, pp. 13, 39).

* **Do all daily notes go into long-term memory?**
  No, not everything is kept. In the OpenClaw memory architecture example, daily notes undergo a nightly automated review ("dreaming") process to drop duplicates, find recurring themes, and move *only* what passes a certain threshold into long-term memory (`MEMORY.md`). One-off lookups stay only in the daily notes so that long-term memory does not bloat (Lecture 3, p. 40).
