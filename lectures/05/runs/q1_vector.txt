Based on Lecture 02:

* **What LoRA freezes and trains:** 
  * It **freezes** the original model weights ($W$), leaving them unchanged (analogous to leaving the main model untouched and adding thin sticky notes). 
  * It **trains** only a small change, or delta, represented as the product of two small, thin matrices ($A$ and $B$) using a low-rank representation (Lecture 2, pp. 51–52).
* **What QLoRA adds:** 
  * QLoRA adds **compression of the original base weights down to 4 bits** (a coarser numerical representation) in addition to using LoRA, which significantly reduces memory usage (Lecture 2, pp. 51–52).
