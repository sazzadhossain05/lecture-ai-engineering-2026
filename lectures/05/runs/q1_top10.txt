According to Lecture 02 (pp. 51–52):

* **LoRA freezes** the original base model weights ($W$), keeping them unchanged (trained weights are not updated there). 
* **LoRA trains** only a small added component represented by two low-rank, thin matrices ($A$ and $B$) that learn the weight changes ($\Delta W$).
* **QLoRA adds** a quantization step: in addition to using LoRA, it compresses the original base model weights to **4 bits** (a coarser numerical representation) to further reduce memory usage.
