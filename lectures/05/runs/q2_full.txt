### 1. How compaction differs from memory across sessions
* **Compaction** works within the context (the same session) by replacing old history with a summary to fit within finite context limits [lec03-main / AI Agents, p. 38, 39]. 
* **Memory across sessions** (such as external storage, the memory tool, or auto memory) stores records externally—such as in files or databases—so that they can be loaded back at the start of a new session [lec03-main / AI Agents, p. 13, 39]. 

### 2. Do all daily notes go into long-term memory?
No, not all daily notes are kept. For example, in systems like OpenClaw, daily notes are reviewed nightly through an automated process (dreaming) where duplicates are dropped, recurring themes are compared, and only what passes a certain threshold is moved into long-term memory (`MEMORY.md`), ensuring that one-off lookups stay only in daily notes and do not bloat long-term memory [lec03-main / AI Agents, p. 40].
