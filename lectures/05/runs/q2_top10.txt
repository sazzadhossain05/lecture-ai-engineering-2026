Based on the Lecture 3 materials (specifically Part 6 on memory), here is how compaction and memory differ, along with how daily notes are handled:

* **Compaction vs. Memory Across Sessions:**
  * **Compaction** works *within a session* (inside the current context) by summarizing history to fit within context limits, replacing old history with a summary (Lecture 3, p. 39, 65).
  * **Memory** operates *across sessions* using external storage (such as files or a memory tool) where information is written out and loaded back into the next context (Lecture 3, p. 13, 39, 65).

* **Do all daily notes go into long-term memory?**
  * No. In the OpenClaw example, a nightly review process (or "dreaming") evaluates the daily notes (`memory/<date>.md`) by dropping duplicates, finding recurring themes, and moving *only* what passes the threshold into long-term memory (`MEMORY.md`) (Lecture 3, p. 40). 
  * As the materials note, one-off lookups stay only in daily notes so that long-term memory does not bloat (Lecture 3, p. 40).
