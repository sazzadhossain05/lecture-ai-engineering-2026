### What is the difference between LoRA and QLoRA?
[model] gemini-3.5-flash-lite
To understand the difference between **LoRA** and **QLoRA**, let's break down how each approach handles the base model weights:

* **LoRA (Low-Rank Adaptation):** This method freezes the pretrained model weights and represents weight updates using a low-rank product of two small matrices, training only those small matrices. While this drastically reduces the number of trainable parameters, the base model weights are typically kept in their standard precision (such as 16-bit) in memory during training.
* **QLoRA (Quantized LoRA):** This builds upon LoRA by introducing **quantization**—such as compressing the base model weights down to 4-bit precision. By doing this, QLoRA significantly reduces the memory footprint of the base model, allowing much larger models to be fine-tuned on smaller, resource-constrained GPUs.

Think about how the precision of the base model weights impacts your GPU memory usage during training. How might loading a model in 4-bit versus 16-bit change what kind of hardware you need for your experiments?
